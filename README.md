# OsEngine Updater

Утилита для обновления локальных копий **[OsEngine](https://github.com/AlexWan/OsEngine)** прямо из официального репозитория.

Принцип: **обновляются только официальные файлы** — всё, чего нет в репозитории (ваши роботы, индикаторы, папки), не трогается никогда. Список ваших папок вести не нужно.

---

## Профиль — главная настройка

В `UpdateOsEngine.config.json` есть поле `Profile`. От него зависит, что делать с папкой `bin`:

| Profile | Для кого | Что с `bin` | Сборка |
|---|---|---|---|
| **`Prebuilt`** | Вы используете готовый движок (`bin/Debug/OsEngine.exe`), а свой код кладёте в `bin/Debug/Custom/...` | **Обновляется** (движок остаётся актуальным) | не запускается |
| **`FromSource`** | Вы собираете решение сами, кастомный код компилируется в движок | **Защищена** (ваша сборка не затирается) | запускается после обновления |

> Важно: если вы собираете свои робота/индикатор **в движок** (например, в VS), ставьте `FromSource`. Иначе `Prebuilt` обновит `bin/Debug/OsEngine.dll` официальной версией.

## Два клика

| Файл | Что делает |
|---|---|
| `1_Update_Now.cmd` | Обновить сейчас (быстро, движок 1:1 с репо). |
| `2_Auto_On.cmd` | Включить автообновление (задание в Планировщике). |
| `3_Auto_Off.cmd` | Выключить автообновление. |
| `4_Auto_Status.cmd` | Показать статус автообновления. |
| `5_New_Copy.cmd` | Создать свежую копию из архива репозитория. |

Обычный сценарий: скопировать папку `OsEngineUpdater` в корень копии → при необходимости поменять `Profile` → нажать `2_Auto_On.cmd` (само обновляется) и/или `1_Update_Now.cmd`.

## Установка

1. Скопируйте папку `OsEngineUpdater` в **корень копии OsEngine** (рядом с `project`).
2. Откройте `UpdateOsEngine.config.json` и выставьте `Profile` (`Prebuilt` или `FromSource`).
3. Готово.

Утилита сама находит корень копии по `project\OsEngine\OsEngine.csproj`. Состояние, манифест и лог лежат в `<копия>\.osengine-updater\` и не таскаются вместе с папкой утилиты.

## Конфигурация — `UpdateOsEngine.config.json`

```json
{
  "Owner": "AlexWan",
  "Repo": "OsEngine",
  "Branch": "master",
  "GitHubToken": "",
  "Profile": "Prebuilt",
  "AutoMode": "Mirror",
  "AutoIntervalMinutes": 1440,
  "UserProtectedPaths": [],
  "BuildAfterUpdate": null
}
```

| Поле | Назначение |
|---|---|
| `Owner`, `Repo`, `Branch` | Источник на GitHub. |
| `GitHubToken` | Личный токен (повышает лимит API). Пусто — анонимно. |
| `Profile` | `Prebuilt` или `FromSource` (см. выше). |
| `AutoMode` | Режим автообновления: `Mirror` (полная сверка) или `Delta` (только изменения). |
| `AutoIntervalMinutes` | Интервал автообновления в минутах (1440 = раз в сутки). |
| `UserProtectedPaths` | Ваши дополнительные исключения (по желанию). |
| `BuildAfterUpdate` | `null` — по профилю; можно жёстко задать `true`/`false`. |

Изменили `Profile`/`AutoIntervalMinutes` — просто снова нажмите `2_Auto_On.cmd` (задание перезапишется).

## Как это работает

- **Правило «только официальные файлы».** Утилита получает дерево файлов репозитория и меняет лишь те пути, что в нём есть. Ваши файлы в дереве отсутствуют → не трогаются.
- **Mirror (режим по умолчанию).** Считает git-blob-SHA локальных файлов и сверяет с деревом GitHub: добавляет отсутствующие, обновляет отличающиеся, удаляет исчезнувшие официальные. Качает только отличия.
- **Profiles.** `Prebuilt` не защищает `bin` → обновляются и бинарники движка. `FromSource` защищает `bin` и пересобирает после обновления.
- **Авто.** Задание в Планировщике запускается при входе и каждые `AutoIntervalMinutes`, в тихом режиме, лог в `<копия>\.osengine-updater\update.log`. Имя задания уникально для каждой копии (`OsEngineUpdate_<hash>`).

## Расширенные параметры

```powershell
powershell -ExecutionPolicy Bypass -File UpdateOsEngine.ps1 [параметры]
```

| Параметр | Описание |
|---|---|
| `-Mirror` | Полная сверка движка с репозиторием (по умолчанию для `1_Update_Now`). |
| `-FullSync` | Полная перекачка из архива (если отстали сильно). |
| `-Bootstrap` | Создать новую копию из архива. |
| `-TargetDir <путь>` | Куда разворачивать при `-Bootstrap`. |
| `-CheckOnly` | Только проверить, ничего не менять. |
| `-NoBuild` | Не собирать проект. |
| `-Watch` | Цикл проверки каждые `AutoIntervalMinutes` (окно держать открытым). |
| `-Silent` | Тихий режим + лог. |

## Важное и ограничения

- **`Profile` ставьте осознанно.** `Prebuilt` затрёт `bin/Debug/OsEngine.dll` официальной версией; если у вас там кастомная сборка — нужен `FromSource`.
- **Ваши правки официальных файлов** будут перезаписаны при обновлении (их нет смысла править — вынесите в `UserProtectedPaths` или в `bin/Custom`).
- **Ваши собственные файлы** (в т.ч. в `bin/Debug/Custom`) сохраняются всегда — они «лишние», утилита их не удаляет.
- **Нет само-восстановления** в `Delta`, в `Mirror` — есть (создаёт отсутствующие официальные файлы).
- **Git-подмодуль** `related projects/FinamApi/finam-trade-api` (gitlink) не зеркалится.
- **Лимит GitHub API** — анонимно 60 запросов/час; при частом авто на нескольких копиях задайте `GitHubToken`.
- **Задание в Планировщике** обычно требует запуска `2_Auto_On.cmd` **от Администратора**.
- **Bootstrap** качает архив целиком (~190 МБ) — используйте для новой копии, а не для ежедневного обновления.
- При ручном скачивании ZIP из браузера снимите веб-метку (`Unblock-File`), иначе MSBuild падает на `Properties\Resources.resx`.
